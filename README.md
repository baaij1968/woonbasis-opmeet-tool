# Woonbasis opmeet-tool — Vloerplanner

Open `index.html` in een browser (ook op telefoon). Geen installatie, geen internet nodig.

- **Ruimtes**: rechthoek, L-vorm, scheve vierhoek (4 muren + diagonaal) of vrije vorm (muur voor muur). Meerdere ruimtes (woonkamer, gang, keuken…) vormen samen één vloer; het patroon loopt overal door.
- **Uitsparingen**: keukenblok, kookeiland, trapgat, kolom… tellen niet mee in m² en plinten.
- **Patronen**: visgraat enkel/dubbel/driedubbel, rechte planken (½, ⅓, ¼ verband), tegels.
- **Echte snij-analyse**: elke plank wordt tegen de plattegrond geknipt → hele planken, zaagstukken, snippers, A/B-aantallen, hergebruik van restjes.
- **Uitzetten**: hartlijn, puntlijn, eerste punt en maten vanaf een echte muur; slim optimaliseren.
- **Materiaal**: bestellijst met pakken, plinten, ondervloer/lijm, profielen.
- Projecten bewaren, export/import, deel-link, afdrukken.

`archief/visgraat-uitzet-v1.html` is de oorspronkelijke versie.
